本文档是《清源水厂》TapTap 小游戏版本的隐私政策。
它替换了此前的 Android APK 版本政策 —— 那一版声称没有接入任何第三方 SDK、游戏里没有广告、
也不申请任何权限，与本项目后来接入 TapTap 登录与激励视频广告的事实不符，已作废。
安卓原生版本若日后真的发布，必须另出一版政策，不能沿用本文件。

一、我们收集哪些信息

本游戏不收集、不存储、不传输任何可以识别您个人身份的信息。

具体而言，本游戏：

  • 不要求注册账号，不索取手机号、邮箱、身份证号；
  • 不读取通讯录、相册、位置、麦克风、摄像头、剪贴板；
  • 不采集设备唯一标识（IMEI / OAID / IDFA / Android ID 等）；
  • 不含任何统计埋点、行为分析或用户画像。

二、TapTap 登录

本游戏运行在 TapTap 小游戏平台上，按平台审核规范接入了 TapTap 登录。

  • 登录只会在您主动点击并同意授权后发生，不会在后台自动进行；
  • 游戏只接收平台返回的一次性授权结果，用于确认「登录已成功」；该结果不做持久化保存；
  • 游戏不调用 TapTap 的用户信息接口，因此不会读取您的昵称、头像、手机号或 TapTap 账号 ID，

也不会把任何登录信息上传到服务器；

  • 用于区分存档的编号是游戏在您本机随机生成的匿名编号，与您的 TapTap 账号无关；
  • 即使您不完成登录，游戏的全部玩法都可以正常进行。

三、游戏存档

您的游戏进度仅保存在本机设备上（通过 TapTap 小游戏平台提供的本地存储写入），

不会上传到任何服务器，我们无法读取，也无法将它与您本人关联。

当前版本尚未启用云存档功能。 若日后启用，我们会在启用前修订本政策并重新征求您的同意。

删除存档有两个入口：直接卸载游戏，或使用游戏内「隐私政策」页底部的「注销账号」按钮

（无需卸载，立即清除本机存档，详见第七节）。两者效果相同。

四、第三方服务与广告

本游戏通过 TapTap 小游戏 SDK 使用宿主（TapTap 小游戏平台）提供的能力：

游戏运行时、TapTap 登录、本地存储、屏幕安全区适配，以及可选的激励视频广告。

  • 激励视频广告只有您主动点击按钮才会播放，不会自动弹出，也不会打断游戏进程；
  • 完整看完视频后才能领取奖励（应急资金或研发加速）；中途关闭则没有任何奖励；
  • 广告的播放、计费与投放统计由 TapTap 小游戏平台及其广告服务商按其各自的隐私政策处理。

我们只接收「是否看完」这一个结果，不接触任何广告标识符或投放数据；

  • 本游戏不含内购、不含抽卡、不含强制插屏广告、不含开屏广告；

不看广告不影响任何主线玩法与通关。

当前版本没有接入任何统计分析 SDK：游戏内预留的统计接口是空实现，数据只在内存中短暂存在，

不会发送到任何服务器，也不会持久化。

五、权限与网络说明

  • 小游戏版本不单独申请任何 Android 权限；权限由 TapTap 小游戏宿主统一持有与管理；
  • 网络能力由宿主提供，仅用于加载游戏资源、完成登录授权、请求广告三件事，

不用于上传您的任何个人信息；

  • 安卓原生版本（如日后发布）不申请任何安卓权限，全程离线运行。

六、未成年人保护

  • 本游戏不含付费数值道具、不含抽卡机制、不含陌生人社交功能；
  • 本游戏不收集任何个人信息，因此不存在针对未成年人的信息收集风险；
  • 若您是未成年人，建议在监护人指导下使用本游戏。

七、您的权利

本游戏不收集任何个人信息，所以我们手里没有您的任何资料可供查询或更正。

删除本机数据的入口是游戏内「隐私政策」页底部的「注销账号」按钮。

本游戏没有服务器账号，本机匿名标识与全部本地存档就是账号的全部内容，

因此注销会立即、不可恢复地清除它们；为避免误触，需要连续点击两次才会执行。

清除完成后页面会显示「已注销」，该按钮随即失效。

您也可以直接卸载游戏，效果等同于删除全部本地存档；

还可以随时在系统或平台侧撤回对 TapTap 的授权。

八、信息安全

本游戏不向自己的服务器上传任何数据，因此不存在我方传输过程中的信息泄露风险。

本地存档由 TapTap 小游戏平台保存在您的设备上，其他应用无法直接读取。

九、政策变更

本政策如有更新，我们将在游戏内「隐私政策」页面与本页面同步公示，并更新顶部的生效日期。

若变更涉及新增信息收集，我们会在新版本启动时以弹窗形式重新征求您的同意。

十、联系我们

如您对本政策有任何疑问、意见或投诉，可通过以下方式联系我们：

  • TapTap 开发者主页：https://developer.taptap.cn/v3/486734/app/978031/store/update
  • 或在 TapTap 本游戏页面留言，我们会尽快回复。
